# Posts (Phase B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship user-authored posts (text + photos + transcoded video + attached ride, public/friends) with composer, feed bodies, thread comments, kudos, and moderation, on self-hosted S3.

**Architecture:** Additive Postgres migration first, then S3 plumbing (SDK + presigned URLs + MinIO), then a single SKIP-LOCKED transcode worker, then posts APIs reusing the friends/events/comments patterns, then composer UI, then feed/detail/comments UI in the Phase A shell.

**Tech Stack:** SvelteKit 2 + Svelte 5 runes, Postgres 16 + RLS, MinIO (S3 API) via `@aws-sdk/client-s3`, ffmpeg 9 (system binary), tsx worker, vitest + happy-dom component tests.

**Spec:** `docs/superpowers/specs/2026-10-04-posts-design.md`

import { randomUUID } from 'crypto';

const BUCKET = process.env.S3_BUCKET ?? 'gradientrip-media';
const REGION = process.env.S3_REGION ?? 'us-east-1';

let client: S3Client | null = null;
export const s3 = (): S3Client => {
	if (!client) {
		client = new S3Client({
			region: REGION,
			endpoint: process.env.S3_ENDPOINT,
			forcePathStyle: true,
			credentials: {
				accessKeyId: process.env.S3_ACCESS_KEY ?? '',
				secretAccessKey: process.env.S3_SECRET_KEY ?? ''
			}
		});
	}
	return client;
};

};
