# Safety (Phase D) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship structured hazard reports on routes (pins, expiry, renewal) surfaced on cards, maps, and in the planner, plus moderation with teeth (hide thresholds, author visibility, crew-admin review).

**Architecture:** Additive migration first (hazards + confirmations + posts.hidden + event hiding), then hazard APIs reusing the posts-create validation copy, then surfacing (a self-contained Leaflet mini-map for route detail, badge counts, planner corridor check over the resampled line), then moderation (mirrored hide triggers, author report views, crew-admin dismiss with audit log), then gate + visual pass.

**Tech Stack:** SvelteKit 2 + Svelte 5 runes, Postgres 16 + RLS + triggers, Leaflet (existing loader + marker patterns), vitest + happy-dom, existing haversine/resample engine utils.

**Spec:** `docs/superpowers/specs/2026-10-11-safety-design.md`
