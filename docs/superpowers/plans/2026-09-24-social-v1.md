# Gradient Social v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build combined social v1 (rich onboarding, public routes, channels, events, home circuits, two-phase feed) on the existing offline-first SvelteKit app without regressing planner/friends/live.

**Architecture:** Additive Postgres tables + RLS mirroring the `is_friend()` pattern; pure TS helpers (geom-hash, scoring, privacy offset, validators) unit-tested with Vitest; Svelte 5 rune state (`channels.svelte.ts`, `feed.svelte.ts`) copying `social.svelte.ts`; new API routes copying `friends/+server.ts`; new tab `channels` beside `friends`.

**Tech Stack:** SvelteKit 2 + Svelte 5 (`adapter-node`), Tailwind v4, Vitest (node env, `src/**/*.test.ts`), Postgres 16 + `scripts/migrate.ts`, Google OAuth + device-cookie auth, Leaflet, Photon/Nominatim/Open-Meteo (existing).

**Spec:** `docs/superpowers/specs/2026-09-24-social-v1-design.md` — the plan argues from the spec, so the spec travels with it; executors read both.

## Global Constraints

- Sports enum is exactly `eskate|ebike|scooter|euc|push|bike|kick` — one line, no other values in v1.
- Board triple format is `capWh|climbPct|brakePct` with `BOARD_RANGES cap[50,5000], climb[1,45], brake[1,30]` from `app/src/lib/state/domain.svelte.ts:53-57`.
- `localStorage` stays source of truth for drafts/onboarding; cloud never overwrites a non-empty local store (`sync.ts` restore rule).
- Public geometry starts ~200m from exact home; test asserts ≥150m to allow rounding tolerance.
- Live positions stay friends-only SSE; nothing public gets live data.
- Verify order in `app/`: `npm run check` → `npm run lint` → `npm test` → `npm run build` (Node 22, CI `release.yml`).
- Prettier: tabs, single quotes, no trailing comma, `printWidth: 100`.
- `display_name` 1–40 chars (`routes/api/profile/+server.ts:30`); comment body 1–500 chars.
- `geom_hash` is a stable hash of the simplified polyline rounded to 5 decimals plus sport.

const SPORTS = new Set(['eskate', 'ebike', 'scooter', 'euc', 'push', 'bike', 'kick']);

export const parseSports = (v: unknown): string[] => {
	if (!Array.isArray(v)) return [];
	return v.filter((s): s is string => typeof s === 'string' && SPORTS.has(s));
};

export const parseHome = (v: unknown): { lat: number; lon: number; label: string } | null => {
	if (!v || typeof v !== 'object') return null;
	const h = v as Record<string, unknown>;
	if (typeof h.lat !== 'number' || typeof h.lon !== 'number' || typeof h.label !== 'string') return null;
	if (!Number.isFinite(h.lat) || !Number.isFinite(h.lon) || !h.label.trim()) return null;
	return { lat: h.lat, lon: h.lon, label: h.label.trim().slice(0, 120) };
};

export const parseUnits = (v: unknown): 'km' => 'km';
```

import { MODES } from '../engine/index.js';
import { parseSports, parseHome } from './profile.js';

export interface OnboardingDraft {
	displayName: string;
	sports: string[];
	modeId: string;
	boardVal: string;
	home: { lat: number; lon: number; label: string } | null;
}

export const coerceDraft = (v: Record<string, unknown>): OnboardingDraft => {
	const rawName = typeof v.displayName === 'string' ? v.displayName.trim().slice(0, 40) : '';
	const modeId = typeof v.modeId === 'string' && MODES[v.modeId] ? v.modeId : 'eskate';
	const boardVal = typeof v.boardVal === 'string' ? v.boardVal : MODES[modeId].boards[0].value;
	return { displayName: rawName, sports: parseSports(v.sports), modeId, boardVal, home: parseHome(v.home) };
};
```

```ts
export const geomHash = (line: [number, number][], sport: string): string => {
	const rounded = line.map(([lat, lon]) => `${lat.toFixed(5)},${lon.toFixed(5)}`).join(';');
	let h = 0;
	const s = `${sport}|${rounded}`;
	for (let i = 0; i < s.length; i++) h = (Math.imul(h, 31) + s.charCodeAt(i)) | 0;
	return `g${(h >>> 0).toString(16)}`;
};
```

```ts
import { json, error, type RequestHandler } from '@sveltejs/kit';
import { withUser } from '$lib/server/db.js';
import { requireAuth } from '$lib/server/auth.js';
import { geomHash } from '$lib/community/geom.js';

export const POST: RequestHandler = async (event) => {
	const me = await requireAuth(event);
	const body = await event.request.json().catch(() => null);
	const title = typeof body?.title === 'string' ? body.title.trim() : '';
	const sport = typeof body?.sport === 'string' ? body.sport : '';
	const line = Array.isArray(body?.line) ? body.line : null;
	if (!title || title.length > 80 || !line || line.length < 2) throw error(400, 'title and line required');
	const hash = geomHash(line, sport);
	const { rows } = await withUser(me.id, async (c) => {
		return c.query(
			`INSERT INTO public_routes (author, title, sport, line, geom_hash) VALUES (current_user_id(), $1, $2, $3, $4)
			 ON CONFLICT (geom_hash, sport) DO NOTHING RETURNING id`,
			[title, sport, JSON.stringify(line), hash]
		);
	});
	if (rows.length === 0) return json({ deduped: true }, { headers: { 'Cache-Control': 'no-store' } });
	return json({ id: rows[0].id, deduped: false }, { headers: { 'Cache-Control': 'no-store' } });
};
```

export const routeScore = (rides: number, saves: number, kudos: number, ageDays: number): number =>
	Math.log(1 + rides + saves * 2 + kudos) - ageDays / 30;

export const fitBadge = (
	totalWh: number, usableWh: number, worstClimb: number, climbLimit: number, worstDescent: number, brakeLimit: number
): 'fly' | 'ok' | 'caution' | 'stop' => {
	if (Math.abs(worstDescent) >= brakeLimit) return 'stop';
	if (totalWh > usableWh) return 'stop';
	if (worstClimb >= climbLimit || totalWh > usableWh * 0.7) return 'caution';
	if (totalWh < usableWh * 0.3) return 'fly';
	return 'ok';
};
```

import { haversine } from './engine/route-geometry/haversine.js';

export const offsetStart = (line: [number, number][], home: [number, number], offsetM: number): [number, number][] => {
	let acc = 0;
	for (let i = 1; i < line.length; i++) {
		acc += haversine(line[i - 1], line[i]);
		if (acc >= offsetM) return line.slice(i);
	}
	return [line[line.length - 1]];
};
```

`buildHomeCircuit` wraps this: takes the planner line for the km target, applies `offsetStart(line, home, 200)`, then scores with engine and returns the same `ScoredResult` shape `domain.applyResult()` expects.
